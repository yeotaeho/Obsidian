### 위 알케미와 알랩빅은 파이썬에서 데이터베이스(DB) 관리의 핵심 라이브러리

### alembic
은 테이블을 수정, 관리, 추적까지 해주는 라이브러리

히스토리을 통해 즉 기록으로 현재 테이블, 이전 테이블, 미래 테이블을 기록
이전의 기록으로 현재 테이블을 수정하다가 오류가 나면 이전 테이블로 복귀할수도 있고

수정(미래 기록?)으로 아, `email` 컬럼이 추가됐네? 라는 내용을 담은 수정 전용 DDL 스크립트를 생성할수도 있음
이렇게 하면 전체적인 공사 순서가 꼬이지 않음
![[Pasted image 20260129162819.png]]


테이블 생성은 

aichemy으로도 가능하지만 히스토리가 안남음 즉 수정이 불가
그래서 alembic을 사용해 히스토리을 남겨 수정이 가능하게 해야함

|**구분**|**SQLAlchemy**|**Alembic**|
|---|---|---|
|**주요 임무**|파이썬 코드 ↔ SQL 통역|DB 구조 변경 이력 관리 및 적용|
|**생성(Create)**|최초 1회 생성 가능|마이그레이션 파일을 통해 생성 가능|
|**수정(Update)**|**불가능** (직접 못함)|**전문 분야** (Alter Table 전문)|
|**삭제(Drop)**|전체 삭제는 가능|특정 컬럼/테이블만 골라서 삭제 가능|

마이그레이션 파일 생성
alembic revision --autogenerate -m "Add pref_domain_json and value columns"

데이터베이스 테이블 업데이트 (실제 SQL 실행)
alembic upgrade head
