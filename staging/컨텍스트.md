## 4. 영속성과 트랜잭션

상태는 **영속 / 준영속 / 비영속 / 삭제**로 나뉩니다. 그리고 **스레드 - 트랜잭션 - 컨텍스트**가 함께 묶입니다.

> **사용자의 요청 1개가 들어오면 스레드가 그 요청에 맞춰 생성되고, 그 안에 트랜잭션이 생성됩니다.**

## 7. 텐서 — 차원으로 보는 구조

| 차원 | 대응 단위 |
| --- | --- |
| 0차원 | 컨트롤러, 서비스, 레포지토리 각각의 단위 |
| 1차원 | 컴포넌트 |
| 2차원 | 컨테이너 |
| 3차원 | 컨텍스트 |

## 8. URI / URL / URN

| 표현 | 맞음? | 이유 |
| --- | --- | --- |
| `URI = URL + URN` | ❌ | 합치는 개념이 아님 |
| `URI ⊃ URL, URN` | ✅ | 상위 개념 |
| `URI = URL or URN` | ✅ | 정확한 정의 |

예시로 구분하면 다음과 같습니다.

```
URL: https://example.com/books/9780134685991
URI: https://example.com/books/9780134685991
URN: 9780134685991
```

## 9. 로드 밸런서와 컨텍스트 매핑

> **컨테이너는 LB(로드 밸런서)에 대응합니다. LB는 URL을 보고 "어느 서버로 보낼지" 결정하는 장치입니다.**

대응 관계를 정리하면 다음과 같습니다.

- **컨테이너** = LB (long id)
- **컨텍스트** = URI
- **컴포넌트** = `@id`

예를 들어 `https://yeotaeho/api/soccer/play`라는 URL에서 `api/soccer` 부분이 URI(엔드포인트)에 해당합니다.
