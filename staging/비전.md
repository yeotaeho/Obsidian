# 컴퓨터 비전과 이미지 생성 — CNN부터 Diffusion까지

컴퓨터 비전(CV)과 이미지 생성 모델을 공부하면서, LLM 영역과 비교해 가며 정리했습니다. 출발점은 베이스 모델인 YOLO였습니다.

- YOLO(베이스 모델): https://www.ultralytics.com/yolo
- 참고 자료: https://wikidocs.net/book/17199

## 1. CNN vs RNN

비전의 기본 신경망 구조를 비교하면 다음과 같습니다.

| 구분 | CNN | RNN |
| --- | --- | --- |
| 보는 구조 | 공간(Spatial) | 순서(Temporal) |
| 핵심 능력 | 패턴 탐지 | 기억 |
| 병렬 처리 | 매우 잘됨 | 어려움 |
| 대표 입력 | 이미지 | 텍스트, 시계열 |
| 단점 | 순서에 약함 | 긴 문장 기억이 어려움 |

대응 관계는 **CNN — CV**, **RNN — LLM**으로 이해했습니다.

## 3. 비전 파운데이션 모델

| 모델 | 역할 |
| --- | --- |
| ViT | 이미지 표현 |
| CLIP | 이미지-텍스트 |
| DINO / DINOv2 | Self-supervised 비전 |
| MAE | 마스킹 기반 표현 학습 |
| SAM | 범용 세그멘테이션 |

관련 개념으로 다이나믹 메서드, 스태틱 메서드가 있습니다.

**CLIP과 Diffusion의 결합 = 멀티모달**입니다. CLIP이 텍스트를 Diffusion이 알아들을 수 있게 변환하면, Diffusion이 이미지를 생성합니다.

## 4. Diffusion(디퓨전)

생성 모델은 `GAN → VAE → Diffusion` 순으로 발전했습니다. LLM 영역과 이미지 생성 영역을 나란히 두면 구조적 대응이 보입니다.

| LLM 영역 | 이미지 생성 영역 |
| --- | --- |
| **Transformer** | **Diffusion** |
| GPT / LLaMA | Stable Diffusion / SDXL |
| Autoregressive (다음 토큰) | Denoising (노이즈 제거) |
| Token | Latent / Pixel |
| Causal Attention | UNet + Time Embedding |

> **Diffusion은 Transformer와 역할·위치가 거의 동일합니다.** 비전에서 ViT가 신경망 구조로 Transformer와 같은 레벨이고, Diffusion은 "어떻게 생성할지"의 패러다임입니다. 따라서 Diffusion이 ViT를 품을 수도 있습니다.

```
Model Paradigm

     └─ Mistral

```

- **LLM**: Autoregressive → Transformer → GPT
- **Image**: Diffusion → UNet/DiT → Stable Diffusion

## 5. 패러다임 · 구조 · 모델 정리

| 층위 | 텍스트 | 이미지 |
| --- | --- | --- |
| 생성 패러다임 | Autoregressive | **Diffusion** |
| 모델 구조 | Transformer | UNet / DiT |
| 파운데이션 모델 | GPT / LLaMA | Stable Diffusion / SDXL |

> **여기서 "기초적"이라는 말은 오래되었거나 단순하다는 뜻이 아닙니다.**
