# 도메인 연결 — Vercel(프론트) + 가비아 DNS + AWS(백) 배포기

로컬에서 잘 돌아가던 프로젝트를 실제 도메인에 올리려면, **프론트는 Vercel에, 백엔드는 AWS에** 배포하고 그 사이를 도메인으로 이어 줘야 했습니다. 이 과정에서 헷갈렸던 용어부터 정리하고 시작합니다.

## 0. 용어 정리 — 도메인과 프로토콜

- `http://13.125.175.218/` 같은 값을 흔히 "도메인"이라 부르지만, 앞의 `http://`는 정확히는 **프로토콜**입니다.
- `www.yeotaeho.kr`는 **도메인 이름**입니다.
- **DNS**: 도메인(주소)과 도메인 이름을 결합해 주는 체계입니다.

Vercel은 Git에 올린 코드와 도메인을 연결해 주는 **중재자** 역할을 합니다.

> **전체 구조: 로컬 프론트 → Git → Vercel → 가비아 → AWS → Git → 로컬 백**

## 4. 백엔드(AWS) 도메인 연결

로컬에서는 `localhost` 주소로 통신했지만, AWS에 올리고 Vercel(프론트)과 연결할 때는 클라우드 환경이라 `localhost:8000` 같은 주소로는 요청을 보낼 수 없습니다.
