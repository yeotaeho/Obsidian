기본 명령어는 다음과 같습니다.

```bash
# 빌드
docker build --tag pakjkwan/api-labzang-com:v1 .

# 런
docker run 6d64299f0ebf

# 푸시
docker push pakjkwan/api-labzang-com:v1
```

이미 만들어진 로컬 이미지에 태그를 붙여 푸시하는 흐름은 다음과 같습니다.

```bash
# 형식: docker tag [로컬이미지] [계정명]/[레포이름]:[태그]
docker tag mlservice yeotaeho/api-yeotaeho-corn:v1

# 1. 태그가 잘 생성됐는지 확인 (리스트에 두 이름이 다 보이면 성공)
docker images

# 2. 도커 허브로 전송: docker push [계정명]/[레포이름]:[태그]
docker push yeotaeho/test:v1
```

## 다음 단계 — 자동화

현재는 Docker Hub에 올린 이미지를 EC2에서 **수동으로 pull**해 빌드하고 있습니다. 다음 목표는 이 과정을 **GitHub Actions에서 자동으로 빌드**되게 만드는 것입니다. Docker ID와 토큰은 이미 GitHub Actions에 저장해 둔 상태이므로, 이후에는 CI 워크플로에서 이 시크릿을 사용해 빌드·푸시·배포를 자동화하면 됩니다.
