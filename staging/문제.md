# SQL 연습 문제 — 축구 DB 조회 쿼리 모음

`player`, `team`, `stadium`, `schedule` 테이블로 구성된 축구 DB를 대상으로 풀어 본 조회 쿼리 모음입니다. `COALESCE`, `JOIN ... USING`, 스칼라 서브쿼리, `COLLATE` 정렬 등을 연습했습니다.

## 6. 수원 팀 선수 키·몸무게 (NULL 처리)

```sql
SELECT
    p.player_name 선수명,
    COALESCE(p.height::text || ' cm', '0') 키,
    COALESCE(p.weight::text || ' kg', '0') 몸무게
FROM player p JOIN team t
USING (team_id)
WHERE t.region_name = '수원'
ORDER BY p.height DESC NULLS LAST;
```

## 7. 수원 팀 선수 BMI 계산

```sql
SELECT
    p.player_name 선수명,
    COALESCE(p.height, 0) 키,
    COALESCE(p.weight, 0) 몸무게,
    CASE
        WHEN p.height IS NULL OR p.weight IS NULL THEN 0
        ELSE ROUND(p.weight / POWER(p.height / 100.0, 2), 1)
    END BMI
FROM player p
WHERE p.team_id = (
    SELECT team_id
    FROM team
    WHERE region_name = '수원'
)
ORDER BY COALESCE(p.height, 0) DESC;
```

## 8. 수원·대전 골키퍼 목록

```sql
SELECT
    t.team_name 팀명,
    p.player_name 선수명
FROM player p
JOIN team t USING (team_id)
WHERE t.region_name IN ('수원', '대전')
  AND p.position = 'GK'
ORDER BY t.team_name ASC,
         p.player_name ASC;
```

## 9. 수원·대전 중 키 180~183 선수

```sql
SELECT
    p.height 키,
    t.team_name 팀명,
    p.player_name 선수명
FROM player p
JOIN team t
USING (team_id)
WHERE t.region_name IN ('수원', '대전')
  AND p.height BETWEEN 180 AND 183
ORDER BY
    p.height ASC,
    t.team_name COLLATE "ucs_basic" ASC,
    p.player_name COLLATE "ucs_basic" ASC;
```

## 10. 포지션이 비어 있는 선수

```sql
SELECT
    t.team_name 팀명,
    p.player_name 선수명
FROM player p
JOIN team t
USING (team_id)
WHERE p.position IS NULL OR p.position = ''
ORDER BY t.team_name ASC,
         p.player_name ASC;
```

## 11. 경기장별 홈팀 (LEFT JOIN)

```sql
SELECT stadium_name, COALESCE(team_name, '홈팀이 없음')
FROM stadium s LEFT JOIN team t
ON t.team_id = s.hometeam_id
ORDER BY team_name COLLATE "C" ASC;
```

## 12. 특정 일자 경기의 홈팀·원정팀 (스칼라 서브쿼리)

```sql
SELECT t.team_name, s.stadium_name, (
        SELECT team_name
        FROM team t2
        WHERE t2.team_id = a.awayteam_id) 원정팀, a.sche_date
FROM schedule a
JOIN stadium s ON a.stadium_id = s.stadium_id
JOIN team t ON s.hometeam_id = t.team_id
JOIN player p ON t.team_id = p.team_id
WHERE a.sche_date = '2012-03-17'
GROUP BY t.team_name, s.stadium_name, a.awayteam_id, a.sche_date
ORDER BY t.team_name COLLATE "C" ASC;
```

## 13. 포항 스틸러스 GK의 해당 일자 경기

```sql
SELECT team_name || ' ' || region_name team_name, player_name, position, stadium_name, sche_date
FROM schedule a
JOIN stadium s
ON a.stadium_id = s.stadium_id
JOIN team t
ON s.hometeam_id = t.team_id
JOIN player p
ON t.team_id = p.team_id
WHERE a.sche_date = '2012-03-17'
  AND region_name = '포항'
  AND team_name = '스틸러스'
  AND position = 'GK'
ORDER BY player_name COLLATE "C" ASC;
```

## 14. 3점 차 이상으로 이긴 경기

```sql
SELECT
    s.stadium_name,
    a.sche_date,
    t.team_name home_team,
    (
        SELECT team_name
        FROM team t2
        WHERE t2.team_id = a.awayteam_id
    ) away_team, home_score, away_score
FROM team t
JOIN stadium s
  ON t.team_id = s.hometeam_id
JOIN schedule a
  ON t.team_id = a.hometeam_id
WHERE a.home_score - a.away_score >= 3;
```

## 15. 경기장-홈팀 조인 상위 20건

```sql
SELECT *
FROM stadium s JOIN team t
ON s.hometeam_id = t.team_id
ORDER BY hometeam_id ASC
LIMIT 20;
```
