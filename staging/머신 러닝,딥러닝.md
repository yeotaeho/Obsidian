# 머신러닝 · 딥러닝 — 학습 방식부터 전처리·모델링 파이프라인까지

머신러닝/딥러닝을 학습하며 정리한 내용을 학습 방식, CI/CD, ML 파이프라인, 전처리·후처리, 모델링 순으로 묶었습니다.

## 1. 학습 방식

- **지도학습**: 정답(라벨)이 있는 데이터로 모델을 훈련합니다. 예를 들어 고양이 사진과 "고양이"라는 라벨을 함께 주면 고양이 사진을 인식하도록 학습합니다.
- **비지도학습**: 정답이 없는 데이터로 데이터 자체의 패턴이나 구조를 스스로 학습합니다. 유사한 상품들을 자동으로 그룹화하는 것이 예입니다("저거 예뻐?" 같은 느낌의, 정답이 정해지지 않은 문제).
- **준지도학습**: 일부 데이터에만 정답이 있는, 혼합된 데이터를 사용합니다.

> **머신러닝에서의 "학습"은, 모델을 가져와 학습시키는 파인튜닝이라고 생각하면 됩니다.**

## 2. 강화학습 (RL)

> **에이전트가 모델을 가져와 학습시키는 방식이 강화학습입니다.**

강화학습의 기본 구조 자체가 **에이전트(Agent)와 환경(Environment)의 상호작용**으로 이루어져 있어서 이렇게 부릅니다. 시행착오를 통해 **보상(점수)을 최대화하는 방향**으로 행동을 학습하며, 지도/비지도 학습을 반복하는 형태로도 볼 수 있습니다.

- **정책(Policy)**: 상태에 따른 액션을 가지고 있는 객체입니다. 모델 내부의 함수가 상태와 가중치에 따라 정책을 만듭니다.

> **SFT 같은 파인튜닝으로 정확도가 70~80%인 것을, 강화학습으로 99%까지 끌어올립니다. 정확도를 높인다기보다 "원하는 대답이 나오게" 하는 것에 가깝습니다.**

### PPO vs DPO

- **PPO**: 환경(루프, 사람)과 직접 상호작용하며 보상을 최대화하도록 정책을 조금씩 업데이트하는 RL 알고리즘입니다. 사람이 피드백을 주며 학습하는, "찐 강화학습"입니다.
- **DPO**: 보상 모델 없이, 인간 선호 데이터만으로 정책을 직접 최적화하는 방법입니다. 사람이 일일이 피드백할 필요가 없습니다.

| 구분 | PPO | DPO |
| --- | --- | --- |
| 알고리즘 계열 | 정책 기반 RL | 선호 기반 최적화 |
| 학습 데이터 | (s, a, r) | (x, y⁺, y⁻) |
| Reward Model | 필요 | ❌ |
| Online 학습 | 가능 | ❌ |
| LLM 파인튜닝 | 복잡 | 간단 |
| 실제 사용 | 범용 RL | LLM 정렬 |

## 8. 데이터 단위 — dataset, dataframe, datawarehouse

- **dataset**: 가장 작은 단위의 데이터 모음입니다. 예를 들어 1990~2024년 데이터 중 2023년 데이터를 가져오는 것이 dataset에 해당하며, **디스크에** 있습니다.
- **dataframe**: dataset에서 필요한 값을 수정해 사용하는 것으로, **메모리에** 올려 수정합니다. dataframe에서는 컬럼을 **피처(feature)** 라고 부르며, 수정 가능한 것은 컬럼이 아니라 피처입니다.
- **database**: 애플리케이션이 실시간으로 사용하는 정형화된 데이터 저장소.
- **data warehouse**: 절대 바뀌지 않는, "역사" 같은 존재. 기업 전체의 방대한 데이터를 장기 보관·분석하기 위한 초대형 저장 시스템.
- 그 외: data store, data mart, data frame.

## 12. 모델

> **모델 = 기계가 스스로 찾아내는 규칙.**

데이터 형태에 따라 모델 알고리즘이 나뉩니다.

- **범주형**(남/여) → 로지스틱 회귀
- **연속형**(167.3, 170, 174.2) → 선형 회귀
- 그 외: 결정 트리, 나이브 베이즈(NB), 랜덤 포레스트(Random Forest)

모델은 **정제된(전처리된) 데이터**를 입력으로 받습니다. 파인튜닝은 특정 작업에 맞게 추가 학습하는 것입니다.

전처리 파이프라인 흐름:

```
피처셋 → df화 → 모델링(이미 존재하는 모델을 튜닝) → 학습 → 평가
```

주의할 개념:

- **아웃라이어(Outlier)**: 평균값을 해치는 제거 대상. 예를 들어 어떤 고등학교의 임금 평균이 높은데 그 이유가 조던 한 명 때문이라면, 조던이 아웃라이어입니다(평균을 흔들어 버림).
- **오버피팅(과적합)**, **accuracy(정확도)** 도 함께 살펴야 합니다.
