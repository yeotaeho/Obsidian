# DSL과 직렬화 — YAML, JSON, QueryDSL

DSL을 정리하면서 가장 와닿았던 한 줄은 **"병렬 구조를 직렬화한다"** 였습니다. 흩어져 있는 구조를 한 줄기로 펴서 다루기 쉽게 만든다는 뜻으로 이해했습니다.

## 언어 = 데이터를 담는 통 + 데이터

저는 언어를 **데이터를 담는 통과 데이터**로 나눠 생각했습니다. 컨테이너·클래스·컴포넌트가 모두 "데이터 통"인 셈입니다.

```
컨테이너(데이터 통) → 클래스(데이터 통) → 컴포넌트(데이터 통)
```

YAML은 빌드할 때 **컨테이너(데이터 통)를 직렬화**합니다.
