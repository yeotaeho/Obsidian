# Setter 메서드 뜯어보기

자바의 setter 메서드를 한 줄씩 뜯어보며 각 구성 요소의 의미를 정리했습니다.

```java
public void setEmail(String email) {
    this.email = email;
}
```

| 코드 요소 | 설명 |
| --- | --- |
| `public` | 이 메서드가 어디서든 접근 가능하도록 하는 접근 제어자입니다. |
| `void` | 이 메서드가 호출된 후 반환(return)하는 값이 없음을 의미합니다. |
| `setEmail` | 메서드의 이름입니다. 일반적으로 `set` + 필드 이름 형태로 짓습니다. |
| `(String email)` | 외부로부터 `String` 타입의 `email`이라는 매개변수(인자)를 입력받음을 의미합니다. |
| `this.email` | 클래스 내부에 선언된 필드(멤버 변수), 즉 객체가 실제로 가지고 있는 이메일 변수를 가리킵니다. |
| `= email;` | 매개변수로 넘어온 값(`email`)을 객체의 필드(`this.email`)에 할당해 값을 설정합니다. |
