# 데이터 — 변수와 상수, 그리고 요청/응답의 직렬화

데이터가 프론트와 백 사이를 오갈 때의 핵심 개념(변수/상수, 요청/응답, 로드밸런서 라우팅, 직렬화)을 정리했습니다.

## 1. 변수(variable)와 상수(constant)

- **응답(Response)**: HTML → Java
- **요청(Request)**: Java → HTML

HTML `input`으로 받은 쿼리스트링을 컨트롤러로 넘기면, 모델(domain + service)로 넘어갑니다.

```html
<input type="text" id="password" name="password" placeholder="비밀번호를 입력하세요" required value="b">
```

여기서 `name="password"`, `value="b"`는 쿼리스트링으로 `?password="b"&` → `?변수=value&` 형태가 됩니다.

> **변수가 데이터로 넘어가면 상수로 바뀝니다.** 사용자가 아이디·비밀번호를 보내면 그 값(value)이 저장되어, 바뀌지 않는 값이 됩니다. 이 값이 "수정"된다고 해도, 기존 값이 바뀌는 게 아니라 **새 값으로 할당**되고 이전 값은 삭제됩니다.

게이트웨이 `yaml`에는 다음 설정이 있습니다.

```yaml
predicates:
  - Path=/api/user/**
filters:
  - StripPrefix=1
```

- `Path=/api/user/**`: `/api/user`로 시작하는 URL일 때 실행됩니다. 그러면 로드밸런싱이 `user-service`로 라우팅하고, 이를 **유레카가 찾아서 보내 줍니다.**
- `StripPrefix=1`: 첫 번째 세그먼트(`api`)를 제거합니다. 그 결과 `http://user-service:8083/user/naver/login`이 `user-service` 컨테이너로 전달됩니다.
