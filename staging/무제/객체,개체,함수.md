# 객체 · 개체 · 함수 — 구성과 명명 규칙

객체를 속성과 기능으로 나눠 이해하고, 자바 코드에서 이들이 어떻게 표기되는지 정리했습니다.

## 1. 지워지는 객체와 지워지지 않는 객체

객체는 **지워지는 객체**와 **지워지지 않는 객체**로 나뉩니다. 애너테이션으로 만들어진 객체는 지워지지 않는 객체(static, 싱글톤)입니다.

## 2. 구성

- **객체** = 속성(정보) + 기능(함수)
- **개체** = 속성(정보)
- **함수** = 기능(함수)

즉 객체는 **전역 변수(프로퍼티) + 기능(함수)** 입니다.

## 3. 명명 규칙

- **객체**: 대문자로 시작 (예: `System`)
- **개체**: 소문자로 시작 (예: `out`)
- **함수**: 소문자로 시작 (예: `abc()`)

이를 한 줄에서 보면 다음과 같습니다.

```java
System.out.println("email = " + email);
//  객체  .개체.  함수
```

참고로 `@GetMapping("/auth/login")` 같은 애너테이션도 객체입니다.
