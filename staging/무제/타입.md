# 자바의 타입 — 기본 타입과 참조 타입

자바의 타입은 크게 **클래스 타입**과 **인터페이스 타입**으로 나뉩니다. 여기서는 특히 기본(Primitive) 타입과 참조(Reference) 타입의 차이를 정리합니다.

대표적인 타입은 다음과 같습니다.

- `String` — 문자열
- `int` — 정수
- `boolean` — 참/거짓
- `float` — 소수
- `char` — 문자
- `System`, `Scanner`

## 참조 타입 vs 기본 타입

이 중 `String`, `System`, `Scanner`는 **참조(Reference) 타입**입니다. 우리가 만들어 낸, 디스크에 저장되어 있는 타입이라, 메모리에서 쓰려면 **주소를 불러 원본을 가져와야** 합니다.

```java
Scanner scanner = new Scanner(System.in);
```

- `Scanner` — 클래스(설계도), 어딘가 디스크에 저장되어 있는 것
- `scanner` — 인스턴스(설계도로 만든 실제 물건), `Scanner`를 기준으로 자료를 가져오는 주체
- `new` — 객체를 메모리에 생성
- `new Scanner(...)` — `Scanner` 클래스를 기반으로 새로운 객체 하나를 만들라고 생성자를 호출하는 부분

반면 `float`, `char`, `boolean`, `int`는 **기본(Primitive) 타입**입니다. 기계에 내장된 타입이라 원본 타입을 따로 불러 변수 설정을 할 필요가 없습니다.

```java
int abc;
```

## 변수의 범위

- **리턴 타입**: 리턴된 값의 타입
- **지역 변수(Local variable)**: 특정 범위 안에서만 유효한 변수
- **전역 변수(Property)**: 속성, 즉 프로퍼티로서 객체 전체에서 접근 가능한 변수
