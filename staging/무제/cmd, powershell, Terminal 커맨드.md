# cmd · PowerShell · Terminal — Windows와 Linux를 잇는 통로

cmd, PowerShell, Terminal, WSL의 관계를 "땅과 통로"라는 비유로 정리했습니다.

## 땅과 통로 비유

운영체제(Windows, macOS, Linux)를 각각 하나의 "땅"이라고 보면,

- **커맨드(command)**: 땅 — 원래 있던 명령 체계
- **PowerShell**: 통로 — Windows에 원래 있던 커맨드를 Linux로 잇는 길
- **Terminal**: 다른 땅 — Windows와 Linux를 연결하는 창구

> **WSL은 이 파이프라인을 만드는 행위입니다.** PowerShell이 길이 되어, Windows라는 땅에 PowerShell을 설치해 Linux라는 다른 땅에 연결합니다.

정리하면, Terminal은 Windows와 Linux를 연결하는 존재이며, WSL(Windows Subsystem for Linux)을 통해 두 운영체제가 이어집니다.
