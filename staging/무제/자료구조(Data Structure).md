# 자료구조 — 선형/비선형 구조와 아키텍처

자료구조를 선형/비선형으로 나눠 이해하고, 이를 언어별 자료형과 소프트웨어 아키텍처로 연결해 정리했습니다.

## 1. 선형 구조 vs 비선형 구조

- **선형 구조**: 리스트처럼 순서대로 나열하는 array 구조 (예: `[1, 2, 3, 4, 5]`)
- **비선형 구조**: 키 값으로 호출하는 JSON 구조 (예: `{name: yeotaeho, age: 22}`)

> **데이터베이스는 비선형 구조입니다.**

언어별로 대응시키면 다음과 같습니다.

| 분류 | 선형(line) | 비선형(non-line) |
| --- | --- | --- |
| 자바 | array, list | map |
| 파이썬 | list | dictionary |
| 자바스크립트 | array | json |

## 2. 아키텍처

기본적인 레이어드 아키텍처는 다음과 같습니다.

```
사용자(브라우저)
   ↓
Controller (요청 받음)
   ↓
Service (비즈니스 로직 처리)
   ↓
Repository (DB 접근)
   ↓
Database (데이터 저장)
```

관련 개념으로 드리븐 아키텍처(DDD, EDA), 워크로드가 있습니다.

가장 기본적인 파이프라인은 다음과 같습니다.

```
타임리프 → 컨트롤러 → 서비스 → 레포지토리(서비스에서 넘어온 기능 역할을 지우고 DB에 전달) → DB
```

여기서 **도메인(Entity)**은 레포지토리에서 이용하는 도메인입니다.

## 3. 엘리먼트(Element)

`[1, 2, 3]`이라는 배열에서 1, 2, 3 각각이 엘리먼트입니다. 즉 데이터베이스 안에 있는 데이터 값을 엘리먼트라고 합니다. HTML에서도 마찬가지입니다.

```html
<div class="card">
    <h1>타이틀</h1>   <!-- h1 태그도 하나의 엘리먼트 -->
    <p>설명 문구</p>   <!-- p 태그도 엘리먼트 -->
</div>
```

- `<div>`: 부모 엘리먼트
- `<h1>`, `<p>`: 자식 엘리먼트
- 속성(`class="card"`)도 엘리먼트의 일부로 간주

## 4. 구조의 세 층위

`List<Map<String, String>>`에서 `<>`가 곧 스트럭처(구조)입니다. "구조"라는 말은 맥락에 따라 세 층위로 나뉩니다.

| 구분 | 의미 | 예시 |
| --- | --- | --- |
| 자료 구조(Data Structure) | 데이터를 저장/관리하는 방식 | List, Map, Struct |
| 소프트웨어 구조(Software Structure) | 코드 계층의 설계 | MVC, Layered Architecture |
| 시스템 구조(System Structure) | 서버/DB 등 전체 연결 구조 | 클라이언트–서버 구조 |

참고로 데이터베이스는 디스크에 저장되며, 그 안의 언어는 모두 자연어에 해당합니다.
