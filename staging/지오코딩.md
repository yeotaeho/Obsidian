지도 위에 데이터를 시각화하기 위해 **Folium(폴리움)** 을 사용했습니다.

## 설치

기본 설치는 pip로 합니다.

```bash
pip install folium
```

아나콘다를 설치했다면, conda-forge 채널로 설치하는 편이 성능이 더 좋았습니다.

```bash
conda install folium -c conda-forge
```
