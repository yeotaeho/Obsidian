### 실전 코드 — 삼성 리포트 자연어 처리

`konlpy(Okt)`와 `nltk`, `wordcloud`로 삼성전자 리포트를 분석하는 코드입니다.

```python
import pandas as pd
import nltk
from nltk.tokenize import sent_tokenize, word_tokenize, RegexpTokenizer
from nltk.stem import PorterStemmer, LancasterStemmer, WordNetLemmatizer
from nltk.tag import pos_tag, untag
from nltk import Text, FreqDist
from wordcloud import WordCloud
import matplotlib.pyplot as plt
import os
from pathlib import Path
from datetime import datetime
from konlpy.tag import Okt
import logging
import re

logger = logging.getLogger(__name__)


class SamsungReport:
    """
    삼성전자 리포트 분석 서비스 클래스
    """

    def __init__(self):
        self.okt = Okt()

    def text_process(self):
        self.find_freq()
        self.draw_wordcloud()
        return {
            '전처리 결과': '완료',
            'freq_txt': freq_txt,
        }

    def read_file(self):
        self.okt.pos("삼성전자 글로벌센터 전자사업부부", stem=True)
        fname = '../data/kr-Report_2018.txt'
        with open(fname, 'r', encoding='utf-8') as f:
            text = f.read()
        return text

    def extract_hangeul(self, text: str):
        temp = text.replace('\n', '')
        tokenizer = re.compile(r'[^ ㄱ-힣]+')
        return tokenizer.sub('', temp)

    def change_token(self, texts):
        return word_tokenize(texts)

    def extract_noun(self):
        # 삼성전자의 스마트폰은 -> 삼성전자 스마트폰
        noun_tokens = []
        tokens = self.change_token(self.extract_hangeul(self.read_file()))
        for i in tokens:
            pos = self.okt.pos(i)
            temp = [j[0] for j in pos if j[1] == 'Noun']
            if len(''.join(temp)) > 1:
                noun_tokens.append(''.join(temp))
        texts = ' '.join(noun_tokens)
        logger.info(texts[:100])
        return texts

    def read_stopword(self):
        self.okt.pos("삼성전자 글로벌센터 전자사업부", stem=True)
        fname = '../data/stopwords.txt'
        with open(fname, 'r', encoding='utf-8') as f:
            stopwords = f.read()
        return stopwords

    def remove_stopword(self):
        texts = self.extract_noun()
        tokens = self.change_token(texts)
        stopwords = self.read_stopword()
        texts = [text for text in tokens
                 if text not in stopwords]
        return texts

    def find_freq(self):
        texts = self.remove_stopword()
        freqtxt = pd.Series(dict(FreqDist(texts))).sort_values(ascending=False)
        logger.info(freqtxt[:30])
        return freqtxt

    def draw_wordcloud(self, filename: str = None, save_path: str = None, show: bool = True):
        """
        워드클라우드 생성 및 저장
        Args:
            filename: 저장할 파일명 (기본값: None, 자동 생성)
            save_path: 저장할 폴더 경로 (기본값: None, app/nlp/save 사용)
            show: 그래프 표시 여부
        Returns:
            저장된 파일 경로
        """
        texts = self.remove_stopword()
        wcloud = WordCloud(
            width=1000,
            height=600,
            relative_scaling=0.2,
            background_color='white'
        ).generate(" ".join(texts))

        if save_path is None:
            current_file = Path(__file__).resolve()
            save_dir = current_file.parent.parent / "save"
        else:
            save_dir = Path(save_path)
        save_dir.mkdir(parents=True, exist_ok=True)

        if filename is None:
            timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
            filename = f"samsung_wordcloud_{timestamp}.png"
        elif not filename.endswith('.png'):
            filename = f"{filename}.png"

        filepath = save_dir / filename
        wcloud.to_file(str(filepath))
        logger.info(f"워드클라우드가 저장되었습니다: {filepath}")

        if show:
            plt.figure(figsize=(12, 12))
            plt.imshow(wcloud, interpolation='bilinear')
            plt.axis('off')
            plt.show()
        return str(filepath)
```

## 4. 퍼셉트론과 신경망

> **딥러닝은 퍼셉트론의 집합입니다. 뉴런이 곧 퍼셉트론이며, 신경망(NN)이 딥러닝의 핵심입니다.**

정형화된 데이터가 다음과 같이 있다면,

```python
X = {
    "review": "난 이거 아직도 생각하면 슬퍼서 운다고..",
    "date": "05.10.15",
    "rating": "10",
    "author": "kiss****",
    "review_id": "443170",
    "movie_id": "10940"
}
```

기계가 알아들을 수 있도록 다음처럼 전처리됩니다.

```python
X = [0.12, 3.5, 0, 10, ...]
```

각 숫자마다 가중치를 부여하는데, 처음에는 거의 의미 없는 **랜덤 값**으로 시작합니다. 그 후 정답(y, 라벨)을 기준으로 비교해 오차(Loss)를 계산하고, 그에 맞춰 가중치를 수정합니다.

> **딥러닝에서는 y에 도달하기 전에 수많은 필터(층)를 거칩니다.**

<!-- TODO: 이미지 업로드 필요 -->
![[Pasted image 20251212174824.png]]
각 필터(층)를 지날 때마다 가중치를 수정하고, 최종적으로 y에 도달하면 정답과 비교해 오차(Loss)를 계산합니다. 오차가 있으면 **역전파**로 수정된 가중치를 가지고 처음부터 다시 돕니다. 이 과정을 반복해 예측 y와 실제 y(정답)가 맞으면 종료합니다.

> **핵심 식: y = wx + b**

반면 **머신러닝에는 역전파 개념도, 필터(층) 개념도 없는 단층 구조**입니다. 대신 로지스틱 회귀, SVM, 결정 트리 등으로 가중치를 수정합니다.

## 6. 모델

신경망 계열은 `NN → ANN → DNN(은닉층이 존재하는 신경망) → CNN, RNN`으로 확장됩니다.

> **모델 = 메커니즘 + 데이터의 조합.**

- **알고리즘**: 학습할 방법, 즉 설계도 같은 개념입니다. 여러 개일 수도, 없을 수도 있지만 **학습하려면 알고리즘이 필수**입니다. 학습이 끝난 모델을 배포할 때는 알고리즘을 제거하고 배포합니다.

## 10. RAG (Retrieval-Augmented Generation)

참고 자료: https://brunch.co.kr/@vsongyev/28

![[Pasted image 20251216125218.png]]

> **여기서 retrieval은 "리트리버(개)가 공을 물어오는" 것을 비유한 것입니다.** 사용자가 질문하면, 의미적으로 관련 있는 정보를 (DB·외부 데이터에서) 물어오는 것을 뜻합니다.

이전의 일반 검색이 "도서관에서 제목으로 책 찾기"였다면, retrieval은 "사서에게 '이런 내용의 책'이라고 말하면 추천받는" 방식입니다.

`GPT = Generative Pre-trained Transformer`(생성형 언어가 학습된 트랜스포머)이며, 이런 GPT 같은 모델을 활용하기 위한 설계도가 **RAG 아키텍처**입니다.

> **RAG은 체인, 즉 파이프라인입니다.** GPT·LLaMA 등 모델과의 연결에 대한 개념입니다.

처리 흐름은 다음과 같습니다.

1. 사용자 질문 입력
2. retriever가 pgvector에서 유사한 문서 3개 검색
3. 검색된 문서를 "문맥"으로 만듦
4. 프롬프트 템플릿에 "문맥 + 질문" 결합
5. ChatGPT(gpt-3.5-turbo)에 전달
6. GPT가 문맥 기반으로 답변 생성
7. 문자열로 파싱하여 반환

전체 데이터 흐름을 도식화하면 다음과 같습니다.

```
[프론트엔드 (Next.js)]
        ↓ HTTP POST /api/chat
        ↓ {"message": "벡터 검색이란?"}
        ↓
[api_server.py]
        ↓
[get_vectorstore()]
  - OpenAI 임베딩 생성
  - RAG_DOCUMENTS를 pgvector에 저장 (최초 1회)
        ↓
[create_rag_chain()]
  - Retriever 생성
  - LLM (gpt-3.5-turbo) 준비
  - 체인 구성
        ↓
[rag_chain.invoke()]
  1. "벡터 검색이란?" → OpenAI로 벡터화
  2. pgvector에서 유사 문서 3개 검색
  3. 문맥 + 질문을 GPT에 전달
  4. GPT 응답: "벡터 검색은..."
        ↓
[ChatResponse]
        ↓ {"response": "벡터 검색은..."}
        ↓
[프론트엔드에 표시]
```

### Vector DB

> **벡터 DB는 정형화되지 않은 데이터(PDF, HWP 등)를 비정형 그대로 저장하는 곳입니다.**

대표적으로 FAISS DB, Chroma DB, pgvector DB 등이 있으며, 그 외에도 많습니다. 각 프로젝트에 맞는 DB를 골라 사용합니다.

## 11. PEFT(파인튜닝)

<!-- TODO: 이미지 업로드 필요 -->
![[Pasted image 20251217111252.png]]

`y = wx + b`에서 `w`(가중치)와 `b`(bias)가 **파라미터**입니다. PEFT는 **이 파라미터의 일부만 학습**시켜, 학습하는 파라미터 수를 줄이는 방법입니다.

> **쉽게 말하면 어댑터 패턴입니다.** 220V를 110V 어댑터로 변환해 쓰듯, 모델에 목적에 맞는 어댑터를 결합해 튜닝 목적에 맞는 데이터만 주는 방식입니다.

PEFT는 튜닝의 **전략(개념)** 이고, 이를 실제로 구현하는 구체적 **방법(알고리즘)이 LoRA**입니다.

전체 학습 파이프라인: **공공데이터 → SFT → QLoRA → DPO → LangGraph 루프**

### SFT (Supervised Fine-Tuning)
> **질문(Input)에 대한 정답(Output)이 쌍으로 구성된 데이터를 학습시키는 과정**을 SFT(지도 미세 조정)라고 합니다.

### RLHF
- **RL**: 강화학습
- **HF**: 사람 피드백(Human Feedback)

### ETL (Extract · Transform · Load)
> **ETL = 데이터를 가져와서(Extract) → 처리하고(Transform) → 저장하는(Load) 자동화 스크립트.**
