# Spring Boot + Thymeleaf, 그리고 컴파일 vs 인터프리터

`Spring Boot + Thymeleaf` 조합에서 API와 UI를 다룰 때 알아 둔 기본 개념을 정리합니다.

## 컴파일 언어 vs 인터프리터 언어

| 구분 | Java | HTML |
| --- | --- | --- |
| 비유 | 번역 | 통역 |
| 클래스 생성 | 클래스를 생성(컴파일) | 클래스를 생성하지 않음 |
| 오류 처리 | 컴파일 오류가 있으면 실행 불가 | 인터프리터 오류가 있어도 실행 가능 |
| 속도 | 느림 | 빠름 |

## MVC

- **Model** — 데이터
- **View** — 화면
- **Controller** — 제어
